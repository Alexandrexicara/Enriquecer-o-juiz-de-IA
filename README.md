# AI Money Builder

A practical 30-day business experiment planner. It helps a user choose a narrow digital offer, allocate a small starting budget, validate demand, plan outreach and track actual results.

## Current MVP
- Responsive Portuguese landing page.
- Budget, market, time and experience inputs.
- Deterministic 30-day plan generator with budget allocation.
- Print-to-PDF output.
- No paid API, account, payment or external service required.

## Run locally
Open `index.html` in a browser, or run a static server:

```bash
python -m http.server 8080
```

Then visit http://localhost:8080.

## Product principles
- No guaranteed-income or get-rich-quick claims.
- Separate budgets, estimates, actual revenue and profit.
- Validate demand before spending.
- No automatic outreach, purchases or financial transactions.

## Roadmap
